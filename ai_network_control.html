AI Networking · 万卡集群利润池

谁能在 AI 网络里
收税？

英伟达的闭环 vs 博通的开放网络 —— 万卡集群之后，硬件利润池正在被重新分配。这不是 InfiniBand 与 Ethernet 谁取代谁的问题，而是谁能在 scale-up、scale-out、scale-across 三层网络里同时收税。

原文作者川沐｜Trumoo（@xiaomustock） 原文摘抄微证券 市场规模$220 亿 / 2026E 长期 CAGR~51%（J.P. Morgan）
三句话总结

01真正发生的，不是 InfiniBand 切到 Ethernet，而是架构控制权从"端口速率升级"上移到"谁定义集群拓扑、交换 ASIC、NIC/DPU、光电接口、系统软件和客户认证"。

02英伟达守的是高端训练闭环的确定性，博通做的是云厂自研 ASIC + 开放 Ethernet 的核心税收层，Marvell 是NVLink Fusion 和光电互连的弹性桥，Arista/Cisco 是订单和收入的验证层。

03投资上的答案不是押单一协议胜负，而是买跨路线收税能力——谁能在多种架构里都拿到收税的位置，谁就能在 1.6T/3.2T 之后继续拿走更高质量的利润池。

读前必备 · 00

八个绕不开的术语

InfiniBand 英伟达的"高速专线"

一种为高性能计算设计的网络协议，延迟极低、专门优化大规模 GPU 训练。被英伟达通过收购 Mellanox 收入囊中，是其闭环生态的关键一环。

像是数据中心里的"私人高铁"——只服务自家乘客，但速度和稳定性最好。
AI Ethernet 改造过的"开放高速公路"

传统以太网为 AI 训练做的增强版——加上 RoCE、UEC（超以太网联盟）、拥塞控制、遥测。代表玩家：博通的 Tomahawk/Jericho、Arista 交换机、英伟达的 Spectrum-X。

公路系统全球通用，所以人人都能造车上路，但要靠 ETC、智能信号灯弥补速度劣势。
NVLink / NVLink Fusion 英伟达的"机柜内总线"

NVLink 是连接 GPU 与 GPU 的专有高速通道。NVLink Fusion 是 2025 年起开放给第三方的版本——允许联发科、Marvell、富士通、高通的 CPU/ASIC 接入英伟达机柜。

原本只准自家品牌零件接入的接口，开始有限度地"对外授权"，是攻是守的暧昧动作。
Scale-up / out / across 三层网络的"距离感"

Scale-up = 一个机柜内（GPU 之间）；scale-out = 多个机柜跨房间互联；scale-across = 跨数据中心、跨园区。三层的距离、带宽、延迟要求完全不同。

同栋楼内打内线 / 同城跨楼宇专线 / 跨城跨省干线——本质都是网络，但分工不同。
Tomahawk / Jericho 博通的"交换机大脑"

博通的两大交换 ASIC 系列。Tomahawk 主打超高带宽（最新 Tomahawk 6 单芯片 102.4 Tbps），Jericho 主打长距离、深缓存。Tomahawk Ultra 把以太网延伸到 scale-up 场景。

数据中心里所有数据包都要经过的"指挥塔"——谁的交换机芯片快、稳、便宜，谁就握住网络的脉门。
SUE / UALink 挑战 NVLink 的"开放联盟"

SUE（Scale-Up Ethernet，博通推动）和 UALink（AMD、Intel、Meta 等联盟）都是想把"机柜内总线"从英伟达专有协议变成开放标准的努力。

几个不想被锁死在苹果接口里的厂商，凑钱想立一套通用 USB-C 标准。
Custom XPU / ASIC 云厂的"自研芯片"

Google TPU、Amazon Trainium、Meta MTIA、Microsoft Maia——超大规模云厂为减少对英伟达依赖而自研的 AI 芯片。设计服务往往外包给博通或 Marvell。

大型连锁餐厅嫌中央厨房（英伟达）太贵，开始自己定制锅碗瓢盆——但还是要找代工厂（博通/Marvell）来做。
CPO / Retimer / AEC / DSP 让信号"不掉链子"的小零件

CPO（共封装光学）、Retimer（信号中继）、AEC（有源电缆）、DSP（数字信号处理器）——都是高速链路两端必须的辅助芯片。代表玩家：Astera、Credo、Marvell。

不会决定路线怎么走，但决定路能不能走通——长距离信号传输前的"放大器和信号处理"。
底层模型 · 01

三层网络，三种战争

01 Scale-Up 机柜内 · 纵向扩展

把一个机柜内的 GPU/ASIC 组成一个逻辑计算单元。距离最短，带宽要求最高，延迟最敏感。这是英伟达 NVLink/NVSwitch 的传统主场——也是 SUE、UALink、PCIe/CXL Fabric 想要撬动的关键阵地。

这一层赢家拿走"机柜系统"的定义权。一旦客户接受了你的 scale-up 标准，整个机柜的 GPU 互联、电源、散热、机架设计都得围着你转。

英伟达 NVLink/NVSwitch NVLink Fusion 博通 SUE / Tomahawk Ultra UALink 联盟 PCIe / CXL Fabric
02 Scale-Out 机柜间 · 横向扩展

多个机柜、pod、训练域之间的互联——典型的"万卡集群网络"。这是市场增量最大、增长最快、参与者最多的一层。InfiniBand 与 AI Ethernet 在这一层正面相遇。

UBS 的估算：Ethernet AI switching 从 2025 年约 $100 亿增长到 2028 年约 $580 亿——5.8 倍。Arista 1Q26 仅产品收入同比就增长 37%，AI Center 全年指引从 32.5 亿上调至 35 亿。

英伟达 InfiniBand / Spectrum-X 博通 Tomahawk / Jericho Arista Etherlink Cisco Silicon One 超以太网联盟 UEC
03 Scale-Across 跨数据中心 · 跨园区调度

多个数据中心、跨园区、电力约束下的算力资源跨域调度。这是 AI 训练规模再上一个数量级后必然出现的难题：单一园区电力不够，必须把训练拆到多地。

博通和 Meta 的多年战略合作明确覆盖 scale-across——说明这一层不再是远期幻想，而是 2027–2029 年正在落地的工程。

博通 Jericho（深缓存、长距） DCI（数据中心互联）光模块 Marvell PAM4 DSP / AEC Ciena / Cisco 长距设备
01 问题定义

第二层利润池不是端口数量，而是架构控制权

第一篇文章已经讲清楚了：1.6T/3.2T 速率升级，价值会从光模块扩散到 交换 ASIC、Retimer/AEC、SerDes、连接器、背板、线卡、高速 PCB/CCL、CPO/NPO/OCS 和系统厂。但第二篇不能继续铺全景地图——那样会沦为材料堆叠。

这一篇只回答一个更靠前的问题：万卡集群选择什么网络架构，谁就能决定后续硬件利润池怎么分。

架构选择决定四件事：

一、GPU/ASIC 在机柜内怎么组成逻辑计算单元（scale-up）；

二、多个机柜、pod 和训练域怎么互联（scale-out）；

三、多个数据中心、园区和电力约束下的算力资源怎么跨域调度（scale-across）；

四、客户愿不愿意把系统调优、可观测性、故障定位、客户认证和供应链交付交给一个平台。

这就是为什么同一张 AI 网络地图里会同时出现英伟达、博通、Marvell、Arista、Cisco、Astera、Credo、光模块、连接器和 PCB/CCL。它们不是简单横向竞争者，而是在不同网络层级里争夺"谁让昂贵 xPU 不空转"的权力。

端口数量、速率和光模块出货是结果；架构控制权才是原因。
02 研报证据矩阵

七份大行研报，验证同一条主线

把这一组研报重新排布后，证据链其实很清楚——每家投行负责证明同一条主线的不同环节：

J.P. Morgan + UBS
证明增量市场在 Ethernet AI switching。JPM 给 2026 年 $220 亿规模 + 51% CAGR；UBS 给 $100B → $580B（2025–2028）。
Bernstein
解释为什么网络芯片增长会快于 xPU。AI 数据中心网络芯片 2030 年约 $1000 亿框架；connectivity/optics、switches 各占 35-45% TAM。
Goldman Sachs ×3
验证 Broadcom、Arista、Cisco 的订单和财务兑现。Broadcom × Meta 多年战略；Arista 1Q26 beat & raise；Cisco F3Q26 AI 超大规模订单上修。
UBS Marvell + Morgan Stanley
验证 Marvell 弹性 + 光电路线。英伟达对 Marvell 战略投资 $20 亿；MS 补充 GTC/OFC 后的 CPO、Spectrum、Quantum 反馈。

这组证据的共同点是：需求不是单纯来自"更多 GPU"，而来自集群规模扩大后的通信复杂度。AI 网络硬件的价值不是平均落到每个端口，而是按架构控制权、silicon 位置、系统交付能力和供应瓶颈重新分配。

Ethernet 变大，但 InfiniBand 没有失效

把 J.P. Morgan、UBS 和 Bernstein 放在一起看，最关键的结论不是"Ethernet 替代 InfiniBand"，而是"Ethernet 的增量市场更大、增长更快、参与者更多"。

InfiniBand 仍是高端训练集群里最成熟的路线之一——尤其适合英伟达 GPU 闭环、低延迟、拥塞控制和大规模训练稳定性要求极高的场景。

但云厂同时追求三件事：性能、成本、供应链选择。

• 高端训练看性能 → 倾向 InfiniBand / NVLink
• 推理集群看成本和可运维 → 倾向 AI Ethernet
• 自研 ASIC看架构自主权 → 倾向开放 scale-up
• 分布式数据中心看跨园区功耗和拓扑重构 → 需要 scale-across

单一路线很难全部满足。多路线共存不是模糊结论，而是客户工程约束下的必然结果。

所以争论"谁替代谁"没有意义。应该追踪客户把新项目放到哪条路线。InfiniBand 的确定性仍在英伟达，高增长斜率更多在 Ethernet、开放 scale-up、NIC/DPU、交换 ASIC、系统平台和光电接口。

玩家拆解 · 04-08

五个角色，五种打法

04 · 守擂 / 确定性

英伟达

NASDAQ : NVDA

闭环仍是高端训练基本盘，
NVLink Fusion 是防御性开放。

真正的壁垒（不止 InfiniBand）

  • GPU + NVLink + NVSwitch + Quantum-X InfiniBand
  • + Spectrum-X Ethernet + ConnectX + BlueField
  • + DOCA + CUDA / NCCL + 整机柜架构

闭环的卖点

  • 训练稳定性、上线时间
  • 尾延迟、拥塞控制、故障定位
  • 大集群最怕昂贵 GPU 等网络

风险

  • 客户把网络决策权转向博通、Marvell、Arista、Cisco 或自研
  • NVLink Fusion 本质是被迫开放
05 · 攻擂 / 弹性

博通

NASDAQ : AVGO

不是 Tomahawk 一家，
是 custom XPU + Ethernet fabric 的平台税。

三层价值叠加

  • Custom XPU/ASIC 帮云厂降低对通用 GPU 的依赖
  • Tomahawk / Jericho 提供高端 Ethernet 和大规模 fabric
  • SUE / Tomahawk Ultra 把 Ethernet 推向 scale-up

关键证据（高盛 4/14 报告）

  • Broadcom × Meta：多年多代战略合作
  • 支持 Meta 的 MTIA 自研芯片
  • 供应链计划延伸到 2029 年，初始承诺 >1GW
  • 明确覆盖 scale-up / out / across

证伪风险

  • 大客户项目推迟、先进节点/封装卡住
  • 英伟达闭环继续保持高份额
06 · 桥梁 / 多入口

Marvell

NASDAQ : MRVL

从 PAM4 DSP 供应商
升级为架构弹性资产。

转折点（UBS 3/31 报告）

  • 英伟达对 Marvell 战略投资 $20 亿
  • 进入 NVLink Fusion 生态
  • 潜在产品包括 scale-up networking

"桥"的角色

  • 英伟达想把 NVLink attach 扩展到第三方 XPU
  • 云厂想自研 ASIC，但不想放弃英伟达 rack-scale
  • Marvell 在两边之间做整合

多入口结构

  • 客户买英伟达闭环 → 经 NVLink Fusion 参与
  • 客户做自研 ASIC → 经 custom silicon 参与
  • 光电接口升级 → 经 DSP/AEC/CPO 参与
07 · 财务验证层

Arista / Cisco

NYSE : ANET / NASDAQ : CSCO

系统厂不是尾部交付，
是把架构故事变成订单和递延收入的层。

  • AI Center 指引 $32.5B → $35B
  • 采购承诺 $89 亿（QoQ +$21 亿）
  • 短期递延收入增加 $9.07 亿

Cisco F3Q26（高盛 5/13）

  • 收入 $158 亿，YoY +12%
  • 网络收入 $88 亿，YoY +25%
  • 产品订单 YoY +35%
  • AI 超大规模订单展望 $50B → $90B
  • Silicon One 在供应约束下相对占优
08 · 落地闸门

Astera / Credo

NASDAQ : ALAB / CRDO

不定义架构，
但决定架构能不能落地。

为什么必须留位置（Bernstein）

  • connectivity/optics 占网络 TAM 的 35-45%
  • switches 占 35-45%
  • NIC/DPU 占 20%，其中芯片价值占 90%+

真实落地的链路

  • scale-up/out/across 漂亮归漂亮
  • 最后都要穿过板级走线、连接器、铜缆
  • Retimer、DSP、NIC/DPU、光电接口
  • 链路不稳定 → 昂贵 xPU 等待、重传、降速

升级路径

  • UALink / PCIe / CXL Fabric / SUE / AEC 渗透加速
  • 从"配套件"升级为"可收费的可靠性资产"
架构路线对照 · 10

四条路线，各自解决什么

InfiniBand AI Ethernet NVLink Fusion SUE / UALink
适合场景 高端训练、确定性要求高、英伟达 GPU 集中部署 规模化、开放生态、成本敏感、多供应商协作 第三方 CPU/XPU 接入英伟达 rack-scale 生态 把 scale-up 从专有互连推向开放、可定制
核心优势 成熟、低延迟、闭环优化 标准化、生态广、单位带宽便宜 英伟达性能 + 客户自研 ASIC 降低供应商锁定、提高自研利用率

市场喜欢把架构竞争写成二选一：InfiniBand vs Ethernet，或者英伟达 vs 开放生态。但真实情况是 —— 多路线共存。

证伪清单 · 12

这条主线最怕把订单写成利润

01

架构替代不按预期发生

如果 InfiniBand 在高端训练里继续维持强势，而 AI Ethernet 在大规模训练的性能、运维、软件生态不如预期 —— 博通、Arista/Cisco 和开放网络链条的弹性会被压低。

02

供应链约束

Arista 已经明确提到 switching ASIC 上游供应约束和组件成本压力。AI 网络不是只有客户需求 —— 交换 ASIC、先进节点、SerDes、光模块、PCB、连接器、散热、电源都可能成为收入确认的瓶颈。

03

云厂自研节奏波动

博通和 Marvell 的弹性都和 hyperscaler 自研 ASIC 项目相关。如果客户推迟架构切换、训练需求转向推理、或者资本支出节奏变化 —— 项目收入会有明显波动。

04

毛利率压力

系统厂订单强，不代表利润率一定好。组件涨价、供应链抢货、客户议价、白盒竞争和软件服务占比变化 —— 都可能让收入兑现慢于市场想象。

结论 · 14

真正的赢家，是能跨路线收税的人

InfiniBand 不会消失

英伟达的闭环在高端训练集群里仍然最有确定性。但云厂不会停止寻找开放替代 —— AI Ethernet、UALink、SUE、NVLink Fusion 会持续抬升开放网络和自研 ASIC 的战略价值。

博通与 Marvell 是路线迁移里最值得深挖的弹性资产

博通的强项是 custom XPU + Tomahawk/Jericho/SUE，Marvell 的强项是 custom ASIC + 光电接口 + NVLink Fusion。二者都不是单纯"卖芯片"，而是在争 AI 集群架构里的关键位置。

Arista 和 Cisco 是财务验证层

一个证明 AI Ethernet 系统可以变成高质量收入和采购承诺，一个证明传统网络巨头仍能拿到 AI 超大规模客户预算。真正值得买单的不是"网络需求强"，而是 —— 订单能不能转收入？收入能不能守毛利率？系统能不能被客户长期认证？

AI 网络不是从 InfiniBand 简单切到 Ethernet，也不是从光模块切到交换机。它本质上是 AI 集群从"买更多 GPU/ASIC"进入"让每一美元算力更少空转"的阶段。

谁能定义这条集群大动脉，谁就能在 1.6T/3.2T 之后继续拿走更高质量的利润池。
