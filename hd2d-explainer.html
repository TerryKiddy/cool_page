02 / HD-2D 是什么

三步配方

HD-2D 这个词是 Square Enix 在《歧路旅人》里叫响的。它不是某种引擎，而是一套"立体布景 + 纸片人 + 灯光滤镜"的混搭做法。拆成三层就懂了：

3D

立体布景 真模型、真灯光

地板、家具、墙——都是有厚度的真 3D 网格（.glb / .obj），吃真实的方向光、环境光和阴影。所以你旋转视角时，桌子会真的露出侧面。这是 "HD" 的底子。

2D

纸片人 billboard 公告板

角色不是 3D 模型，而是一张 2D 贴纸，贴在一个永远旋转着正对镜头的小平面上（Godot 里叫 Sprite3D + billboard）。你怎么转，它都"扭头"看你，于是这张薄片看起来像个站着的小人。这是 "2D"。

FX

灯光滤镜 辉光 + 移轴 + 近邻采样

辉光(Bloom) 让亮处溢光，出电影感；移轴景深 把上下虚化、只留中间清晰，骗大脑"这是个微缩沙盘模型"；贴图用 nearest 近邻采样，让像素保持锐利不发糊。三件套一上，"塑料感"立刻变"高级感"。

一句话记牢：HD-2D = 把 2D 贴纸角色，放进一个打了电影灯光的 3D 微缩模型里。 上面那个 Live 画面，关掉「2D 纸片角色」就退回纯 3D，关掉「辉光/移轴」就退回塑料玩具——HD-2D 的魔法全在这几层的叠加。
03 / botmux 怎么用它

每个会话 = 一个上班的机器人

这套 HD-2D 场景在 botmux 里不是摆设，它实时映射你的 AI 会话状态。

STEP 1

会话 → 机器人

每个活跃的 CLI 会话，在办公室里对应一个机器人工位。游戏每隔一会儿轮询 /api/sessions 同源接口拿状态。

→
STEP 2

角色 → 贴纸

会话的角色（backend / frontend / pm / tester / 甚至 barista、gym）决定挂哪张 2D 贴纸和模型——就是 roles/ 目录里那堆 png。

→
STEP 3

屏幕状态 → 动画

会话在干活/发呆/出错，映射成机器人的动作。.pck 里那些 jog / crouch / taichi / sad 动画就是给不同状态准备的。
