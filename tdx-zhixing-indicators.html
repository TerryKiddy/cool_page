◆核心改动 / 为什么更好

原版框架（双均线 + 振荡器 + 拐点选股）是经典配方，问题全在执行：重复、混量纲、把简单 KDJ 包装得很玄、还残缺了空头侧。逐项收拾如下。

原问题处理
EMA(EMA(C,10),10) 双重平滑 = 纯加滞后换 DEMA 2·EMA−EMA(EMA)，平滑度不变、滞后约减半
MA1/MA2/BB 死代码、全角 ；、红持绿空:=0 画不出全部删除 / 修正
砖型图：伪 Renko、±100/−90 offset 全抵消、两变量互补不独立、IF(>4) 砍掉空头侧换成 SMI（Blau 随机动量指数）——它就是「平滑随机指标」的标准对称版，0 轴对称、含空头侧
0~180 振荡器与价格同窗 → Y 轴被撑爆拆三个公式，振荡器进副图，互不干扰量纲
两条均线类指标功能重叠改成 快(DEMA10)+慢(EMA55)配对，靠交叉定方向，不再冗余
XG 单凭动能拐头 → 震荡市满屏假信号加 趋势过滤（C>EMA55）+ 限定 零轴下方金叉，大幅降 whipsaw

2通达信里怎么新建

入口：菜单 功能 → 公式系统 → 公式管理器。左侧是分类树，三段属于两个类别。

公式建在哪关键设置
① 趋势系统技术指标公式 → 新建必须勾「主图叠加」✅
② SMI 动量技术指标公式 → 新建不要勾「主图叠加」❌（默认副图）
③ 选股条件选股公式 → 新建无叠加选项

每个公式的新建流程

  1. 选好分类 → 点 新建，弹出编辑窗口。
  2. 公式名称 填英文/数字（如 ZXTREND、ZXSMI、ZXXG）。注意：公式名本身只能字母数字；但代码里 短期趋势线:、多空线: 这种输出行用中文是允许的。
  3. 把对应那段代码粘进 公式编辑 大文本框。
  4. 点 测试公式 做语法检查 → 没报错 → 确定。

调出来看

  • ① 主图叠加：保存后在 K 线图上敲公式名 ZXTREND 回车，白/黄线就叠到 K 线上。
  • ② 副图：副图区域右键 → 选择指标公式 → 找到 ZXSMI；或副图敲名字回车。
  • ③ 选股：菜单 功能 → 选股器 → 条件选股，选中 ZXXG → 执行选股。
⚠️

这一步是「量纲坑」的根治点

① 勾主图叠加、② 千万别勾。 勾反了：SMI（−100~+100）要么飘在 K 线上方一团乱，要么趋势线被丢进一个跟价格脱节的小副图里。

参数：代码里 N:=14; 这些已写死，粘进去就能用，不必填参数表。想用滑块调，就删掉那行 := 定义，改在上方「参数」表里建 N 并设缺省值。

3这些备注会不会报错？

✅

不会。

代码里所有注释用的都是 { ... }，这是通达信官方注释符，单行/多行、行尾跟在 ; 后都合法。注释里的中文、↑↓、[贴到:…] 路由提示都只是文本，安全。看完想删也行。

真正会报错的是这几样（顺手排雷，按概率）：

① 全角标点混进代码区。 这是原版踩过的坑（那个全角 ；）。本页代码 ; , ( ) : 全是半角；从网页/聊天复制时偶尔会被转成全角 ；，（）——粘进去前扫一眼，连大括号 { } 也要半角。
② // 双斜杠注释老版本不认会报错。所以本页全程没用 //，统一 { }，最稳。

一句话：注释放心留着，唯一要盯的是别让全角符号溜进代码本身。粘完点一次 测试公式，通过就万事大吉。

4调参 & 变体

  • 更灵敏：减小 N/R/S（如 10/2/2）；更稳：加大（如 21/5/3）。超买超卖线 ±40 可按品种改 ±50。
  • 连续突破型买点：把 ③ 选股里的 SMI<0 删掉即可（信号变多，需自行控仓）。
  • 慢线换回四均线复合：把 EMA(CLOSE,55) 换成 (MA(C,5)+MA(C,10)+MA(C,20)+MA(C,60))/4，①②③ 三处保持一致即可。
